## Monte Carlo验证

固定种子20260917；每个场景生成60份独立数据，每份生成900人（Cox左截断后人数可减少）。共10个场景、600份数据；600份均完成预定估计。完整数值及Monte Carlo区间见 [模拟验证表](five_studies_simulation_validation.csv)。

| 模型 | 真系数 | 平均偏差 | 偏差MC标准误 | 95%区间覆盖率 | 拒绝率 |
|---|---:|---:|---:|---:|---:|
| HC3线性回归 | 0 | 0.0031 | 0.0056 | 95.0% | 5.0% |
| HC3线性回归 | 0.4 | -0.0019 | 0.0064 | 95.0% | 100% |
| 多分类logistic | 0 | -0.0125 | 0.0113 | 95.0% | 5.0% |
| 多分类logistic | 0.4 | -0.0041 | 0.0127 | 93.3% | 100% |
| 延迟入组Cox | 0 | 0.0116 | 0.0065 | 98.3% | 1.7% |
| 延迟入组Cox | 0.4 | -0.0002 | 0.0084 | 95.0% | 100% |
| 协变量MAR缺失＋MI线性回归 | 0 | -0.0244 | 0.0056 | 95.0% | 5.0% |
| 协变量MAR缺失＋MI线性回归 | 0.4 | -0.0251 | 0.0058 | 91.7% | 100% |
| Cox样条两参数交互 | 0 | -0.0109 | 0.0187 | 91.7% | 5.0% |
| Cox样条两参数交互 | 0.4 | -0.00002 | 0.0145 | 95.0% | 100% |

Cox交互行的偏差与覆盖率针对第一个交互系数；拒绝率针对两个交互系数的联合检验。已知交互场景第二个交互系数为-0.1。MI模拟为每份数据5份插补、3次迭代。

每场景只有60次重复，因此误差率和覆盖率的估计仍有明显Monte Carlo不确定性。例如拒绝率5%的Wilson 95%区间为1.7%–13.7%；覆盖率91.7%的区间为81.9%–96.4%。零假设场景的拒绝率是I类错误率；这里不将它误称为完成了真实数据的FDR验证。

**已知限制：**插补模拟出现约-0.025的平均偏差，大于该模拟的偏差MC标准误。不能据此宣称插补无偏、已验证MAR，或已保证真实非线性模型的覆盖率。保留完整病例敏感性分析，并检查真实数据的缺失模式与插补轨迹；实际研究中多重插补和联合检验仍依赖统计分析计划所列假设。五项Holm及研究内BH采用固定检验家族，其校正不是重复模拟中上述拒绝率的含义。

复现模拟：

```bash
python scripts/validate_studies.py --repetitions 60 --n 900 --output outputs/synthetic/validation_new
python scripts/validate_studies.py --family cox_interaction --repetitions 60 --n 900 --output outputs/synthetic/interaction_new
```
