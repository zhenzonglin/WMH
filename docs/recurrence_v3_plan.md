# CNSR-III Hcy–WMH五年复发统计分析计划 v3

修订日期：2026-09-17。实施入口：`wmh-hcy recurrence`。本版在查看一年分析结果后形成，五年为修订后的主要分析，不描述成原先已预注册的确认性检验。原一年H1–H4及长期扩展方案、代码和结果保留。

## 1. 研究问题与假设

基线Hcy与五年首次缺血性卒中复发的关联，是否因WMH负担而不同？

唯一主要检验为连续Hcy×连续WMH。零假设为交互系数等于0，备择假设为不等于0，双侧α=0.05。正交互表示WMH增加时Hcy的相对风险关联增强，负交互表示减弱。研究估计调整后的原因别风险关联，不估计治疗效果或个人绝对复发概率。[1]

## 2. 数据来源与共同基线队列

临床来源为目录下递归扫描的多份SAS文件。仅提取`recurrence_data.SOURCES`白名单，保留来源、标签、原始日期格式与特殊缺失记录。`code_n`作为字符串精确连接，不模糊匹配、不补前导零猜测编码。重复ID或同一变量多个来源未选择时停止，不自动合并冲突值。

成年、缺血性卒中、基线Hcy>0、校正全脑WMH≥0、真实ICV>0、基线采血时间及五年事件/实际删失时间有效者进入候选队列。WMH不得超过ICV。真实ICV沿用DLMUSE 702；不把20区域WMH之和当成全脑值。

以发病日为时间尺度，实际基线采血日为进入时间，使用(entry, exit]风险区间。采血当日或之前已复发者排除；采血之后、三个月之内复发者保留。MRI间隔、中心、人工影像质控状态、T1灰质、三个月血液和mRS不构成主队列门槛。年龄用于判定成年，故年龄未知者不能进入队列。

主终点固定为`Y5_IS`和`Y5_IS_DD`。DD按已确定的数据接口解释为发病至首次缺血性复发或有效观察终止的天数；观察终止必须包括死亡或失访后停止观察。**不要求完成五年随访。** 例如非事件DD=200者在200天删失，不能延长到1825天。状态为1但事件超过1825天者在1825天行政删失。

既有一至四年缺血性卒中记录只核验首次事件一致性，不替换五年终点，也不要求逐年齐全。既往已确认首次事件而五年记录否认事件，或首次事件日期冲突，均单列原因排除；已知死亡日早于所提供观察结束也单列排除。缺少长期死亡日期时不推算，报告依赖供应端DD正确反映观察终止的条件。病例流程和所有排除原因存为本地CSV。

## 4. 固定模型与变量尺度

原因别Cox模型使用PHReg、Efron并列事件和延迟入组。模型包括H、W、年龄的主效应、各一个限制性立方样条非线性项、一个H×W及固定调整集合。

- H=log2(Hcy)减五年队列均值。
- W=[log(1+WMH mL)减五年队列均值]/五年队列标准差。
- H、W、年龄各使用第10、50、90百分位三个节点；中心、尺度、节点一次冻结，七个随访截止时间共用。
- B12、叶酸、胱抑素C取log2；ICV按100mL缩放；采血日连续进入。
- 性别、吸烟、饮酒、高血压、糖尿病、既往卒中按既定字典分类编码，不把类别编码当成连续剂量。
- 主模型不含B12交互，不含其他标志物、mRS、T1或三个月风险更新。

## 5. 协变量选择依据

按修正析取原因准则，根据事先指定的时间顺序和变量角色选择暴露或结局的原因、共同原因的代理指标，排除已知工具变量及结构后代。相关性、单因素P值、逐步回归或机器学习重要性不能替代因果角色判断。[2] `adjustment.py`、`docs/covariate_rationale.csv`保留既有依据；每次运行输出本版`covariate_roles.csv`。

|变量|主模型角色|
|---|---|
|年龄、性别|预设人口学背景原因|
|B12、叶酸|影响Hcy代谢与结局解读的营养代谢背景|
|胱抑素C|肾功能相关共同背景的代理指标|
|吸烟、饮酒|既往生活方式原因|
|高血压、糖尿病、既往卒中|既往血管背景及结局原因|
|ICV、采血距发病日|测量大小与急性期测量时点因素|

NIHSS、TOAST和急性梗死体积描述本次卒中状态，可能改变条件关联的含义，只用于预设临床扩展。扩展模型与同一子样本上的核心模型比较，避免样本变化被误解为协变量调整的影响。角色判断依赖临床假设，不声称已消除全部混杂。

## 6. 插补与合并

生产默认50份插补、10次迭代、种子20260912。一次核心miceforest链式插补产生一套完成数据，七个时点共同使用，避免七次独立插补。

只插补调整变量散在缺失；ID、Hcy、WMH、事件状态、事件/删失天数及整列未测变量不插补。完全未测B12等核心协变量使主模型不可估计，不能用模型自动创造整项检测。原始观测值保持不变。

插补模型包括暴露、H×W、入组和退出时间，以及七个时点的事件、是否可进入该风险集及考虑延迟入组的Nelson–Aalen累计风险辅助量。[3] 某时点尚未入组者的辅助事件/风险填0，并同时携带不可进入指示；这只是预测变量编码，不生成随访记录。非线性与交互的相容性为近似，报告完整病例敏感性及插补均值轨迹。

每份完成数据单独拟合，系数及线性对比用Rubin规则合并。任一插补拟合失败，整个对应分析标记不可估计并报告失败位置，不丢弃失败插补后只合并成功部分。没有缺失时直接拟合一次，不生成50份相同数据。

## 7. 三类主要输出

1. 五年交互HR之比、95%CI、双侧P值。单位为WMH相差1个log体积标准差时，Hcy每翻倍对应HR的比值。
2. WMH第25、50、75百分位下Hcy 15对10 μmol/L的HR与95%CI。
3. Hcy 15对10的HR随WMH变化的曲线。

有非线性Hcy主效应时，Hcy15对10不是简单对交互HR取幂；代码改变两个Hcy值后计算完整设计矩阵差c，以c′β和c′Vc（包含所有协方差项）合并。不需要bootstrap。

对每个WMH展示点，在其±10个百分点的WMH观测窗检查Hcy的第5–95百分位是否同时覆盖10和15。若不覆盖，该点标记UNSUPPORTED并留空，不外推也不换成能得到显著结果的参考值。百分位不是临床阈值，区间为逐项95%CI。

## 8. 敏感性与时间变化

六个其他月份的交互P值单独构成固定六项Holm家族。不可估计项在校正内部占据一个P=1的位置，输出仍为空。五年P值单独报告。七个时间点共享患者和事件，不是独立重复验证，不因某个月显著而改变主要结论。

仅60个月运行三项稳健性分析：完整病例；原始WMH；NIHSS+TOAST+急性梗死体积临床扩展。原始WMH使用同一基线队列中原始体积可用者，并按替换后的WMH重新进行兼容插补；其W均值、标准差和节点来自该子样本，Hcy及年龄尺度保持主要模型定义。临床扩展以急性病灶体积可用者为子样本，共享一次扩展插补完成数据拟合核心和扩展模型。三项稳健性不与七个月份交叉组合。

固定一次时间变化敏感性：在发病90天处分裂(entry, exit]区间，90天事件归早期；晚期从90天之后至1825天。允许H、H的非线性项、W、W的非线性项及H×W随晚期指示变化，其余协变量系数不变。在单个Cox模型检验H×W×晚期项，报告早期、晚期交互及二者差异。使用完整协方差计算晚期系数之和的方差。分裂不创建新患者，不将两个区间当作两次独立事件。

若有时间变化信号，五年常系数结果作为总体模型摘要，分段结果同时解释。残差时间相关仅为描述性筛查，不冒充正式总体比例风险检验。

## 9. 数值诊断与失败规则

记录每次拟合事件数、参数数、矩阵秩、信息矩阵条件数、标准化得分、优化器、残差时间相关与影响量。时间分裂模型的影响量按区间行描述，不能当成逐患者删除分析。

沿用已验证的无惩罚Cox求解：Newton失败时，可用等价中心化/缩放坐标的BFGS初始化并Newton精化，检验回转后的参数和协方差。该步骤不改变模型或目标函数。常量列、秩不足、非有限估计或校验失败均报告，不自动删协变量或改用惩罚模型。

## 10. 输出、版本和复现

每次运行写入`outputs/real/recurrence_v3/runs/<UTC时间>/`。`latest_run.json`指向最近尝试，`latest_results.json`只更新到完成模型阶段的v3运行。旧版根目录、longterm指针和结果不修改。

核心文件：`field_audit.csv`、`cohort_flow.csv`、`cohort_counts.csv`、`endpoint_audit.json`、`horizon_results.csv`、`clinical_contrasts.csv`、`clinical_contrast_curve.csv`、`robustness_results.csv`、`diagnostic_summary.csv`、`report.html`。各模型保存完整系数、协方差、冻结设计和诊断。`cohort.csv`、`participants.csv`、`exclusions.csv`含患者信息，只留本地，不上传GitHub。

主流程约为7×50次复发拟合，另有预设稳健性和时间变化模型。旧配置中的bootstrap及绝对风险参数不会被此入口读取。实际样本数和事件数由工作站审计生成，不沿用旧一年例数。
