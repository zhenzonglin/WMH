# 2—5年随访扩展：实施与统计方案

版本：2026-09-17。研究者已提供2—5年终点字段及示例值。本扩展在已看到一年结果后增加，属于补充探索性分析，一年H1—H4结果与原检验层级保留。

## 实施顺序

1. 扩充SAS白名单，按原目录递归查找新字段；审计每年的事件状态、观察时长、mRS及跨年记录一致性。
2. 从已连接的基线临床与影像建立每年独立队列，不以一年随访完整或五年资料齐全作为入组条件。
3. 分别执行H2长期复发、H3三个月测量后的长期复发、H4长期mRS及T1补充分析；保留逐项状态与失败原因。
4. 汇总全部年份的估计、置信区间、原始P值及多重比较校正值；生成中文报告和森林图。
5. 用合成数据验证提取、删失、早期事件、缺失、死亡评分、模型及报告，随后推送工作站代码。

SAS字段匹配不区分大小写，提取元数据保留原拼写。截图中同一事件日期跨年重复，而未复发者也有截止或提前结束时间；据此使用与一年接口相同的累计首次事件口径，`_dd`按发病至事件/删失的天数接入。状态0是删失，状态1是事件；未知状态不作为0，缺失时间不补成完整随访。超过对应行政截止的观察时间被截断，其后的事件不计入该期限。

同时提取截图中2—5年的STROKE、STROKE_DD、HS、HS_DD作字段审计和后续接口，首轮模型仍使用缺血性卒中，不混合卒中类型。未提供2—5年完整死亡日期，不新增死亡字段、不推算死亡日期，不生成竞争风险绝对发生概率。Cox使用来源表提供的终止时间，其解释依赖该时间确实已包含死亡/失访停止观察这一数据定义。

## 假设与模型

- **H2长期扩展：**基线Hcy与首次缺血性复发的关联随基线WMH变化。在2、3、4、5年累计期限分别拟合延迟入组Cox，起点为实际基线采血日，终点为各年IS_DD与行政截止的较小值。Hcy、WMH、年龄保留三节点样条，Hcy×WMH保留一项线性交互。采用现有核心调整集合，不按本轮P值增加或删除协变量。
- **H3长期扩展：**三个月Hcy在基线Hcy、WMH及背景因素之外与其后复发相关。以实际三个月采血日进入各年风险集；采血前/同日复发者仅不进入H3，仍可进入H2。沿用基线Hcy非线性项、基线Hcy×WMH及同期B12/叶酸/肾功能调整，报告三个月Hcy 15对10 μmol/L条件HR。
- **H4长期扩展：**基线Hcy×WMH与各年较差mRS相关。逐年有序logistic模型，使用该年的mRS 0—6，不要求复发终点完整。保留既往mRS、NIHSS、TOAST、急性梗死体积及核心背景因素；T1子分析加入GM119。明确记录的6分保留；缺失mRS不填0或6。已知死亡日期仅在不晚于目标期限时用于赋6分；更晚年份的6分不倒推早期死亡。

所有模型按各自队列固定转换参数并保存；WMH一个标准差的数值可能随队列不同，不能仅比较不同年份交互HR的大小就声称随时间增强。各年为同一队列的累计期限分析，事件和病例重叠，不是四次独立验证，也不等同于复发次数或年发生率。

协变量散在缺失沿用50份多重插补及Rubin合并。长期Cox插补使用缺血终点、延迟入组时间及对应累计风险辅助量；不伪造长期死亡辅助量。长期mRS插补使用本年的mRS而非12个月mRS，不要求缺血终点完整。暴露、结局状态、事件/删失时间和整项未测指标不插补。

H2、H3、H4分别构成固定4年检验家族，各家族使用Holm校正。不能估计或未运行的年份仍保留在家族中，不因结果缺失缩小检验数；T1补充另列4年探索家族。报告原始P值、校正P值及逐项95%区间，区间不是同时置信区间。保留阴性和不精确结果，不将扩展年份中单个显著P值替换一年主分析。

## 可重复性与输出

长期分析单独写入`outputs/real/longterm/`，不改写一年`latest_results.json`及其模型结果。新年份字段缺失或数据矛盾只影响对应分析，并保存病例排除规则、人数和诊断；不重新推断中心、不使用MRI间隔、不恢复影像人工质控门槛。

方法接口依据：statsmodels [PHReg](https://www.statsmodels.org/stable/generated/statsmodels.duration.hazard_regression.PHReg.html)支持事件/删失时间、延迟入组与Efron并列处理；[OrderedModel](https://www.statsmodels.org/stable/generated/statsmodels.miscmodels.ordinal_model.OrderedModel.html)用于有序结局。混杂选择和缺失处理沿用主方案的VanderWeele、White与Royston及多重插补文献，见`statistical_analysis_plan.md`。
