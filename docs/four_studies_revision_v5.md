# 第五版 CEC非法值排除和一键分析

2026年9月18日，研究者要求排除CEC异常值，并在一次命令内完成准备和全部分析。版本为 `imaging_four_studies_20260918_v5`。本次不改变四项主问题、模型、协变量、50份插补及多重比较家庭。

## 数据规则

- CEC负值、非有限值和非空不可解析值不能进入CEC的任何模型。原始数据只读，派生数据保留非法值标记和首次排除原因，不插补该暴露。
- 零值继续允许；普通缺失不等同于非法值；有限高值不会因为极端或分位数而自动删除。
- `field_audit.csv`保留全体和入组后非法值计数，`cohort_flow.csv`将非法CEC与普通CEC缺失分开计数。原已被其他条件排除者不重复计算。
- 该规则只作用于CEC队列。其他三项不以CEC完整性限制入组。其他必要字段的真实问题仍明确报告。

## 一次启动

```bash
wmh-study start
```

默认四项，自动重新提取当前输入、准备、检查、拟合及报告。无需单独执行audit或输入第二条模型命令。`start --study cec`可单项重跑，`--config`可指定配置。旧audit、run、diagnose接口继续保留。

输入错误只阻断对应研究，其余独立研究继续。失败返回非零退出码；不以旧结果或合成数据替代。每次输出独立时间戳目录，旧合同结果保留但不纳入本版Holm汇总。
